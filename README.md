# C++ Code Like You Are in the MATRIX: Mastering C++ 

This repository contains my source code, exercises, and projects completed during the **[C++ Code Like you are in MATRIX : Mastering C++ in 13 Hours](https://www.udemy.com/course/c-programming-for-everyone/)** course on Udemy by OCSALY Academy.

The goal of this repository is to build a rock-solid foundation in C++ programming, transitioning from basic control structures to complex low-level manipulations and advanced software architecture.

---

## 📂 Course Syllabus & Modules

### 🔹 Section 1: C++ Fundamentals
*   **01.** Writing in CPP (Introduction to syntax and environment setup)
*   **02.** Assigning Variables and Comma
*   **03.** Playing with Variables and Values
*   **04.** Enum (Enumerated types)
*   **05.** Literals, `iomanip` (Input/Output manipulation), and Pointers
*   **06.** Namespaces
*   **07.** Scopes
*   **08.** Arithmetic Operations
*   **09.** Increment and Decrement
*   **10.** Control Statements (Conditional logic)
*   **11.** Loops in C++ (`for`, `while`, `do-while`)
*   **12.** Final Project of This Section

### 🔹 Core Programming Concepts
*   **Data Types & Variables:** Mastering primitive types, Character types, and Boolean types.
*   **Basic Code Principles:** Structuring clean, efficient, and readable code.
*   **Functions:** Parameter passing, function signatures, and modular design.
*   **Arrays & Pointers:** Understanding memory addresses, pointer arithmetic, and managing contiguous data.
*   **String Manipulation:** Working with standard strings and text processing.

### 🔹 Object-Oriented Programming (OOP)
*   Classes and Objects
*   Constructors and Destructors
*   Inheritance and Polymorphism

### 🔹 Advanced C++ & Software Engineering Principles
*   **Dynamic Memory Allocation:** Managing memory manually using `new` and `delete`.
*   **Templates & STL:** Writing generic code and utilizing the Standard Template Library (Containers, Iterators, Algorithms).
*   **Recursion & Backtracking:** Solving complex algorithmic problems using self-referencing functions.
*   **Multi-threading & Concurrency:** Developing parallel applications to maximize CPU performance.
*   **File Input/Output (I/O):** Reading from and writing data permanently to external files.
*   **Debugging & Optimization:** Code optimization techniques and error handling using Exception Handling (`try-catch` blocks).
